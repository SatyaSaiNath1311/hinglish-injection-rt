# Handover checklist (for the paper writer)

- [ ] All result tables in results/tables/ (CSV) and figures in results/figures/ (PNG + PDF)
- [ ] docs/FINDINGS.md: each claim linked to its table or figure
- [ ] docs/METHODS.md fully filled
- [ ] Dataset card + README reproduction commands tested from a clean clone
- [ ] Detector versions, seeds, and compute recorded
- [ ] Negative results and limitations written down
- [ ] Ethics notes: what data is released and why
- [ ] Walkthrough call or recording done
